# Clinical TabReD: experimental results (16 Nov 2026)

All numbers come from `results_summary/` (tables, `summary.md`) and the per-dataset folders
`results_nhanes/` (NHANES), `results_brfss/`, `results_natality/`. Figures are in `figures/`
(PNG + PDF + SVG, captions in `figures/captions.md`;
diagrams d01-d03 from `scripts/make_diagrams.py`). Everything is regenerated by:

```
python scripts/run_benchmark.py --dataset {nhanes,brfss,natality}   # 5 models x 7 splits
python scripts/run_cv.py        --dataset {nhanes,brfss,natality}   # 5-fold CV
python scripts/analyze_drift.py      --dataset {nhanes,brfss,natality}   # drift analysis
python scripts/summarize_benchmarks.py && python scripts/make_figures.py && python scripts/make_diagrams.py
python scripts/make_presentation_pack.py                                # for_presentation/
```
Run the jobs **one at a time**: XGBoost/LightGBM/scikit-learn each start one thread per core, and two
jobs in parallel slowed both down 10-50x (thread oversubscription).

## 1. Question and setup

**Thesis (course brief P034):** build a clinical TabReD, a temporal-drift tabular benchmark from
clinical data, with each drift characterised by its clinical cause.
**Research question:** do TabReD's conclusions hold on healthcare data?
TabReD's claims tested here: (1) random splits misjudge performance on future data and can change the
model ranking; (2) GBDTs (and MLPs) are the strongest models, and XGBoost's lead over the MLP shrinks
under time splits; (3) feature richness changes conclusions.

| | NHANES | BRFSS | Natality |
|---|---|---|---|
| Source | interview + exam + lab | telephone survey | birth certificate |
| Target | diagnosed diabetes | diagnosed diabetes | preterm birth (< 37 weeks) |
| Periods | 7 two-year cycles 2005-2018 | 7 years 2017-2023 | 9 years 2016-2024 |
| Rows x features | 37,287 x 280 | 350,000 x 93 | 450,000 x 73 |
| Positive rate | 13.3% (10.4% -> 16.4%) | 13.6% (flat, dip 2020) | 10.2% (9.6% -> 10.5%) |

**Splits** (TabReD construction): default time split (train past / validate next period / test later
periods), 3 sliding windows (train 3 periods, validate 1, test 1), and 3 random splits of the same
sizes built by shuffling each window's rows.

| Dataset | Default: train / val / test | Sliding-window test periods |
|---|---|---|
| NHANES | 2005-12 / 2013-14 / 2015-18 | 2013-14, 2015-16, 2017-18 |
| BRFSS | 2017-20 / 2021 / 2022-23 | 2021, 2022, 2023 |
| Natality | 2016-21 / 2022 / 2023-24 | 2020, 2022, 2024 |

**Models:** logistic regression, random forest, XGBoost, LightGBM, MLP (scikit-learn). Small grids,
selection by validation PR-AUC, threshold = max F1 on validation, test scored once.
**Metrics:** ROC-AUC (main; independent of prevalence), PR-AUC, accuracy, precision, recall, F1,
confusion matrix; 95% bootstrap CIs (1,000 resamples) and paired bootstrap model differences;
5-fold CV on the development periods (course requirement).

## 2. Main results

### 2.1 Model comparison on the default time split (figures fig02, fig04, fig05)

| Dataset | Best on test (ROC-AUC) | Spread across models | Selected on validation |
|---|---|---|---|
| NHANES | XGBoost 0.900 [0.892, 0.908], LightGBM 0.899 | 0.876-0.900 (0.024) | MLP (0.887): significantly worse than XGBoost (-0.014) and LightGBM (-0.013) |
| BRFSS | LightGBM 0.826 [0.823, 0.829] | 0.821-0.826 (0.005) | XGBoost (0.824): LightGBM significantly better (+0.002), MLP tied |
| Natality | XGBoost 0.750 [0.745, 0.756] = LightGBM | 0.744-0.750 (0.006) | XGBoost: significantly better than MLP, LR, RF (+0.005 to +0.006) |

- **GBDTs are the best models on all three datasets** (TabReD claim 2 holds). Differences are small
  in absolute terms but significant with paired bootstrap CIs.
- **The feature-rich dataset separates models most.** NHANES (280 features) spreads 0.024 ROC-AUC;
  BRFSS (93) and natality (73) only 0.005-0.006.
- In NHANES the model chosen on the validation period (MLP) is significantly worse on the later test
  years: validating on one period does not guarantee the best model for the next.
- Threshold metrics (max-F1 threshold from validation): recall 0.66-0.72 (NHANES), 0.57-0.61 (BRFSS),
  0.34-0.42 (natality); precision 0.47-0.57, 0.37-0.38, 0.35-0.42.

### 2.2 Random vs time splits: TabReD's comparison (figure fig03)

Mean over the 3 windows, ROC-AUC (random minus time; positive = random split looks better):

| Dataset | Random minus time | Significant model-windows | Ranking changes? |
|---|---|---|---|
| NHANES | +0.000 to +0.010 | 4 of 15 (all in window 1, test 2015-16) | **Yes**: MLP 4th (time) vs 2nd (random); LightGBM 1st vs 3rd |
| BRFSS | +0.006 to +0.007 (all models) | 9 of 15 (5/5 test 2021, 4/5 test 2022, 0/5 test 2023) | No |
| Natality | **-0.003 to -0.006** (time looks better) | 3 of 15 (window 0, test 2020, negative) | **Yes**: MLP 3rd vs 5th; LR 4th vs 3rd |

- In the two diabetes datasets, random splits **overestimate** performance on future data, as
  TabReD says. In NHANES, random splits also **change the ranking**: the MLP looks as good as the GBDTs
  under random splits but falls to 4th under time splits.
- In natality, the opposite happens: time splits look *better*. See 2.3 for why.

### 2.3 Random vs time on the same test period (new analysis; figure fig10)

TabReD's random and time test sets contain **different periods** (the random test mixes all periods of
the window; the time test is the last period only). If later periods are easier or harder to predict,
that alone changes the difference. We therefore also scored the random-split model only on its test
rows from the time split's test period.

- **Natality:** later years are intrinsically more predictable. Inside the random split's own test set,
  XGBoost scores 0.735 on 2016 rows rising to 0.761 on 2020 rows (informative risk factors such as
  gestational hypertension become more common). On the same period the random-time difference is
  small and never significant (mean -0.002 to -0.005). **No evidence that random splits overestimate
  for preterm birth**; the "time looks better" result in 2.2 is a period-difficulty artefact.
- **BRFSS:** on the same period the random split is higher in **all 15 model-windows**
  (+0.002 to +0.007; individually not significant with ~10,000 rows per window, but 15/15 same sign).
  Consistent, small optimism of random splits.
- **NHANES:** window 1 (2015-16) +0.012 to +0.025 (not significant, ~1,000 rows); window 2 (2017-18)
  the pooled random-split model is **significantly worse** on 2017-18 respondents (-0.04): within its
  own test set its ROC-AUC falls from 0.93 (2009-10) to 0.86 (2017-18). Plausible explanation (not
  tested): the 2017-18 laboratory analyzer change (2.5) makes lab features inconsistent when shifted
  and unshifted values are pooled in training.
- **Methodological point for the report:** TabReD's random-vs-time comparison mixes "the model has not
  seen this period" with "this period is easier or harder". A same-period comparison separates them
  and changes the conclusion for natality.

### 2.4 TabReD Table 4: relative improvement over the MLP (%)

| Dataset | Splits | Logistic Regression | Random Forest | XGBoost | LightGBM |
|---|---|---|---|---|---|
| NHANES | time | +0.09 | -2.00 | **+0.97** | **+0.99** |
| NHANES | random | -0.08 | -1.94 | +0.28 | -0.00 |
| BRFSS | time | -0.20 | -0.23 | +0.24 | +0.28 |
| BRFSS | random | -0.22 | -0.35 | +0.19 | +0.24 |
| Natality | time | -0.07 | -0.22 | +0.84 | +0.83 |
| Natality | random | +0.23 | +0.15 | +0.85 | +1.03 |

TabReD found that XGBoost's lead over the MLP **shrinks** under time splits. Here it does **not**:
it grows in NHANES (+0.28% random -> +0.97% time), is similar in BRFSS (+0.19% -> +0.24%) and natality
(+0.85% -> +0.84%). In clinical data the GBDT advantage is *hidden* by random splits, not inflated by
them. (Caveat: our MLP is a plain scikit-learn MLP, not TabReD's tuned MLP/MLP-PLR.)

### 2.6 Does drift explain the performance gaps? (`results_summary/drift_performance.csv`)

| Window (test) | Domain AUC | Random minus time | Changes hitting the test period |
|---|---|---|---|
| NHANES w0 (2013-14) | 0.86 | -0.006 (0/5 sig.) | hematology analyzer change |
| NHANES w1 (2015-16) | 0.92 | **+0.020 (4/5 sig.)** | prevalence 12.6% -> 15.1%; ACA coverage change |
| NHANES w2 (2017-18) | **0.97** | +0.004 (0/5) | biochemistry analyzer + lab change |
| BRFSS w0 (2021) | 0.79 | **+0.008 (5/5)** | PERSDOC + insurance question rewording |
| BRFSS w1 (2022) | 0.78 | **+0.008 (4/5)** | race question change |
| BRFSS w2 (2023) | 0.77 | +0.005 (0/5) | none documented |
| Natality w0 (2020) | 0.57 | -0.011 (3/5, negative) | COVID-19 year (father info); later years easier |
| Natality w1 (2022) | 0.56 | -0.003 (0/5) | none |
| Natality w2 (2024) | 0.55 | -0.000 (0/5) | none |

- **More covariate shift does not mean a bigger performance drop.** The strongest shift (NHANES
  2017-18, the lab analyzer change: domain AUC 0.97) causes no significant gap; the significant gap
  (2015-16) comes with the **label shift** (prevalence jump) and the ACA population change.
- **Coding revisions coincide with gaps in BRFSS.** Significant random-split optimism appears in the
  test years with questionnaire revisions (2021, 2022) and disappears in 2023, where no revision was
  found.
- **Natality has little covariate shift** (domain AUC 0.55-0.59) and no random-split optimism; its
  main temporal effect is that the task becomes slightly easier as risk factors become more common.

## 3. Answer to the research question (summary)

| TabReD claim | NHANES (280 features) | BRFSS (93) | Natality (73) |
|---|---|---|---|
| Random splits overestimate future performance | Yes, in the label-shift window | Yes, small but consistent, in coding-revision years | **No** (apparent opposite is a period-difficulty artefact) |
| Random splits change the model ranking | **Yes** (MLP 2nd -> 4th) | No | Partly (MLP, LR; GBDTs stay on top) |
| GBDTs are the strongest models | Yes | Yes | Yes |
| XGBoost's lead over the MLP shrinks under time splits | **No, it grows** | No (similar) | No (same) |

Short version: GBDTs stay best in clinical data; random splits overestimate and reshuffle models in
the feature-rich NHANES data and slightly overestimate in BRFSS, but not in natality; how much depends
on the *type* of drift (label shift and coding revisions matter, measurement-instrument shifts and
smooth trends matter less), not on how large the covariate shift is.

## 4. Limitations

- One seed and small hyperparameter grids (TabReD: 15 seeds, 100 Optuna trials); significance is
  judged with bootstrap CIs instead.
- Models: no CatBoost and no MLP-PLR / FT-Transformer (TabReD's strongest deep models); our MLP is
  scikit-learn's.
- Random and time test sets differ in rows (as in TabReD); the same-period analysis uses ~1,000
  (NHANES) or ~10,000 (BRFSS, natality) random-split rows, so its CIs are wide.
- BRFSS and natality are below TabReD's feature range (feature counts were not padded; see
  `docs/HANDOFF_BRFSS_NATALITY.md`).
- The lab-instrument explanation for NHANES window 2 and the risk-factor explanation for natality's
  rising predictability are hypotheses consistent with the data, not tested causally.
- Survey weights are not used; NHANES/BRFSS samples are different people each period; natality has no
  mother ID.
